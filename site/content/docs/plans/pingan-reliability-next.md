# 后续收口顺序

本文件是待推进计划，不能当作已实现能力。仍以现有产品流程为边界，不自动复制另一产品，不自动增加新 Sprint 或收费模型调用。

1. 查清本地视频模板预览的长等待，并验收加载失败、超时和取消行为；不通过延长模型 timeout 或假输出绕过。
2. 统一各页加载错误、404、未配置及空数据表达；修正未提取却显示完成、卡片统计等误导状态。
3. 扩展现有表单的保存竞争和草稿恢复测试，尤其标题、剧本摘录与章节原文，不声称镜头详情队列已覆盖全站。
4. 服务端生成防重/未知提交结果处理，明确幂等范围、生命周期及失败后的安全重试；设计获确认后再实施，不用前端锁冒充服务端保障。
5. 收口上游免费测试收集错误及 13 项失败，保持真实契约，不能删测试或隐藏失败来宣布全绿。
6. 分别验收真实生产与安全准备：模型配置、费用边界、人审流程、生成与媒体交付；企业隔离、私有素材与备份。需要单独确认实际调用范围和预算，未授权不触发付费生成。
