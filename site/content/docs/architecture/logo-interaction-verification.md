## 同名上传覆盖修复

## 素材空值输入校验

本地真实 PATCH name=null 复现 HTTP 500，原因是可选输入被直接写入数据库非空字段。服务层现区分未传字段与显式 null：name/thumbnail/tags 的 null 在任何修改前返回 HTTP 400；空字符串与空列表仍按原契约允许，不擅自新增业务限制。三项参数化回归验证拒绝后原值未改以及合法清空操作；文件相关 13 项通过。通用服务、角色创建关联、任务状态、演员风格和模板类别另组 29 项通过，没有真实模型调用。
