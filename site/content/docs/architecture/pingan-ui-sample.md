# 平安科技界面样板

## 当前范围

用户最初确认名称为“平安剧场”，现已进一步确认更名为“平安科技”；产品副标题仍为“AI 短剧工作台”。2026-10-03 按用户最新确认，以已登录的 [巨日禄](https://video.jurilu.com/project_management) 工作区为交互参考，替换此前的暖色侧栏样板。历史验收记录保留当时的名称及样式。

2026-10-02 用户确认修复切页换肤问题：同一套品牌主题和公共导航现已覆盖所有业务路由，不再仅限定项目列表和分镜工作室。各页原有业务布局和操作保持独立。

用户进一步确认主线为“上传剧本 → 拆分镜 → 资产图 → 视频生成”。现已按该顺序收拢入口，不再默认把十个项目标签并列展示。以下“主流程”描述的是当前界面，而不是后续计划。

## 四步创作主流程

| 步骤 | 当前操作 | 边界 |
| --- | --- | --- |
| 上传剧本 | 打开项目默认进入剧本列表；导入 TXT 或粘贴文本，填写本集名称并保存 | 每次保存一集，不自动拆集；TXT 要求 UTF-8、非空、最大 2MB；不声称支持 DOCX/PDF |
| 拆分镜 | 选择一集进入现有分镜列表，主动发起提取，检查与确认镜头信息 | 从剧本页点击“下一步”只导航，不直接创建收费提取任务；分镜编辑仍负责基础信息、资产和对白确认 |
| 资产图 | 项目中的角色图、演员图、场景图、道具图、服装图收纳在同一步，复用原有资产页面及图片操作 | 资产仍需真实关联；选择步骤不自动创建资产、确认候选或调用模型 |
| 视频生成 | 选择一集进入原工作室，左侧选镜头，右侧优先显示视频生成和关键帧与参考图 | 继续使用现有视频准备度检查；信息已确认不等于可以生成；其他参数、诊断和维护入口在“高级设置” |

- 顶部四步导航覆盖项目、分镜列表、镜头编辑、工作室和带项目返回路径的资产编辑页。步骤高亮仅表示当前位置，不画虚假的完成对勾。
- 当前章节随“拆分镜 → 资产图 → 视频生成”链接保留。没有章节上下文时展示章节选择，不默认选择其他集，也不启动任务。
- 空项目或尚无镜头时，章节选择页明确引导补剧本或先拆分镜。
- 项目概览、文件、设置和剪辑从“更多”进入，原有深链保留。
- 顶部横向导航优先展示“项目管理”和“资产库”；模板、模型、系统设置收纳到“高级工具”。
- 首页默认展示搜索、新建、添加项目卡片和现有项目卡片；筛选、排序、切换视图、速览及批量管理在“筛选与管理”中展开。
- 剧本默认以章节卡片展示原文摘要、镜头数量、实际准备状态和下一步操作；点击名称编辑原文，“更多”保留原有操作。“列表视图”可以切回表格。
- 新建项目的风格、种子和生成设置默认折叠，但仍保留原默认值和编辑能力。
- 导入文件先读取到本地编辑框，再由用户保存。格式/编码/大小错误不会覆盖草稿；已有文字时导入需要确认替换。保存失败保留输入，并允许重试。
- 新手引导同步介绍四步主线，继续保留本浏览器的完成/关闭记录。
- 视频页“生成前检查”使用中文条件名称，先展示未满足条件，完整检查项按需展开；后端原始检查、阻塞理由和提交校验保持不变。

主要实现：`components/CreationFlow.tsx`、`components/creationFlowRoutes.ts`、`components/ScriptInput.tsx`、`components/scriptImport.ts`、`ProjectWorkbench/index.tsx`。使用既有 generated client 保存章节，无后端 API 或数据库变更。

本次只读观察参考站的项目、片段、角色与视频素材页面和新建弹窗，提取可见控件样式。借鉴顶部导航、黑色背景、深灰面板、紫粉渐变按钮、胶囊标签、卡片添加入口；没有创建第三方项目、提交任务、下载封面/代码或复制品牌素材。品牌 SVG 继续使用本地“平安”标识，改为紫粉渐变。上游 Jellyfish 的 LICENSE、版权和历史不变。

使用网页复刻技能的页面观察和比对方法，但按既有项目规则在 React/Vite 工程中原位修改，不新建 Next.js 工程或额外的产品内设计文档面板。交互设计记录保存在本架构文档。

## 实现边界

- 技术栈仍为 React / Vite / Ant Design；不建立 Next.js 第二套前端。
- `front/src/theme/pingan.ts` 管理唯一的 `pinganTheme`，已删除按路由启用样板的判断。
- `front/src/main.tsx` 的根 ConfigProvider 一次应用全站深色主题（Ant Design darkAlgorithm），弹窗和其他 portal 组件同步继承。
- `front/src/styles/pingan-workspace.css` 使用 `pa-shell` 统一公共导航与基础样式；`pa-library`、`pa-studio` 仍仅控制对应页面布局。
- `front/src/layouts/MainLayout.tsx` 使用统一顶部导航，不按路径切换主题，保留路由、任务中心及 runtime provider。项目内返回按钮回到项目剧本页；项目根页面返回项目列表。
- `ProjectLobby.tsx` 和 `ChapterStudio.tsx` 调整呈现、入口与可访问性；任务、存储和生成能力继续复用原有 service。
- 主按钮使用紫粉渐变；品牌色规则排除 danger 和 disabled 按钮。语义状态色保留。中性 gray/slate 工具类在公共页面、弹窗和抽屉中统一适配深色，避免原有白色背景与浅文字冲突。
- 原有 `jellyfish_language` 和分镜布局 localStorage key 保留，不因更名丢失浏览器偏好。
- 界面验收发现并修复原版属性面板“收起后立即自动打开”：自动展开只响应镜头选择、确认状态或偏好变化，不再依赖 `inspectorOpen` 的关闭动作。仍按原版未就绪条件自动展开，不修改镜头或生成状态。
- 未修改 backend、OpenAPI、generated client、数据库、模型供应商、Prompt 或任何业务状态契约。没有真实模型调用。
- 不移植旧平安剧场的导演引擎及人工质量门，不宣布旧 F04 通过。

## 验收

在 `front/` 运行：

```bash
npm run typecheck
npm run test:ui
npm run build
```

`test:ui` 覆盖品牌一致性、偏好 key 保留、统一根主题、横向导航、主题不改写状态颜色、danger 按钮隔离、弹窗深色适配、剧本卡片操作、键盘焦点和减少动画样式，并包含已交付保存可靠性测试。它不是全部业务或模型生成的端到端测试。

浏览器验收入口：<http://localhost:7788/projects>。从现有项目进入章节的分镜工作室可检查三栏样板。需实际确认搜索、筛选、视图切换、新建弹窗、项目跳转、属性面板收起/展开和标签切换。不要点击模型提取或生成来验收视觉。
