本次检查平安科技现有 Jellyfish 本地界面的滚动、底部内容可达性、长弹窗、中文标签和页面跳转。已修复确认的布局及导航缺陷，但不等于所有业务功能已交付。本轮没有真实模型调用，没有修改业务记录，没有创建新的产品能力，也没有变更 API、领域 Schema、PRD 或质量门。

## 已修复的问题

1. 普通页面没有滚动兜底。固定高度外壳曾裁切自然高度页面，提示词模板在 1280×600 窗口下无法看到底部分页。MainLayout 的 `pa-page-viewport` 现在允许溢出滚动；固定布局工作室继续管理各自面板。
2. 项目标签页内容被裁切。工作台头部保持不收缩，`pa-project-tab-content` 提供有界滚动。仪表盘、文件及占位标签超出可视高度时可查看底部。
3. 设置页出现 `settings.title` 等资源标识。页面现在使用明确的 settings 命名空间；实际显示系统设置、昵称、角色、深色模式等中文文字。没有改变权限或设置保存逻辑。
4. 分镜列表直接显示 pending。仅将现有状态展示为待确认、生成中、已就绪，数据库状态及准备规则不变。
5. 章节导航指向不存在的独立路由。共用 `getProjectChaptersPath` 现在指向项目的 chapters 标签；仪表盘查看全部及后期页返回章节使用有效地址。
6. 镜头编辑页加载失败时自动跳回列表，隐藏了原因。失败现在保留在当前页，显示中文错误和重试入口；404 会提示检查镜头细节记录，不自动补造数据。有效镜头的原有编辑和确认布局保留。
