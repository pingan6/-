## 已修复并验证

- 手动镜头创建缺详情：显式摄影字段与镜头同事务保存，失败回滚，未自动确认。
- 工作室镜头卡片与时长缓存串用：匹配 shot ID，旧详情不写入新选择镜头缓存。
- 同名素材覆盖：独立对象路径，真实上传/下载哈希一致；旧记录与文件保留。
- 文件引用层级错误：项目/章节/镜头关联一致性校验，真实错误引用返回 400。
- 素材 null 导致 500：非空数据库字段写入前拒绝显式 null，真实接口返回 400，原值保留。
- 本地静态刷新导致 API 地址丢失、新手引导导航位置文案错误：配置与文案已修复。
- 测试设施缺失候选查询及响应 meta 预期过时：测试修复，不算作产品功能或产品 BUG 修复。
